Installation

  1. Prepare

    • Back up all data (photos, contacts, 2FA keys).
    • Charge the battery to at least 70%.
    • Update to the latest stable OxygenOS.
    • Install the latest Google Platform Tools (ADB and Fastboot).

  2. Enable OEM unlocking

    1. Go to Settings → About device → Version.
    2. Tap Build number 7 times to enable Developer options.
    3. Open Settings → Additional settings → Developer options.
    4. Turn on USB debugging and OEM unlocking.

  3. Unlock the bootloader

    Connect the phone over USB and reboot to fastboot:

    adb reboot bootloader

    Check that your computer sees the device:

    fastboot devices

    Start the unlock:

    fastboot flashing unlock

    On the phone, use the volume keys to pick UNLOCK THE BOOTLOADER and confirm with power.

  4. Flash boot images and recovery

    Extract the release archive, then flash the images in order:

    fastboot flash init_boot init_boot.img
fastboot flash boot boot.img
fastboot flash vendor_boot vendor_boot.img
fastboot flash recovery recovery.img
fastboot -w
fastboot reboot recovery

  5. Sideload LineageOS

    In LineageOS Recovery:

    1. Choose Factory reset → Format data / factory reset.
    2. Go back and choose Apply update → Apply from ADB.
    3. Run the sideload from your computer:
    adb sideload lineage-24.0-*.zip

    If it stops with Error 7, wipe the super partition from fastboot and try again:

    fastboot wipe-super super_empty.img
fastboot reboot recovery

  6. First boot

    Choose Reboot system now. The first boot takes about 60–90 seconds.

    Later updates arrive in Settings → System → Updater.
